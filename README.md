Uma aplicação web simples e interativa para conversão bidirecional entre unidades do sistema métrico e imperial (Comprimento, Volume e Massa).
Projeto desenvolvido como parte do curso Full Stack Developer do **Scrimba**.

## ✨ Funcionalidades
- **Conversão de Comprimento:** Metros para Pés e Pés para Metros.
- **Conversão de Volume:** Litros para Galões e Galões para Litros.
- **Conversão de Massa:** Quilogramas para Libras e Libras para Quilogramas.
- **Validação de Entrada:** Impede cálculos com valores vazios.
- **Precisão Decimal:** Resultados formatados com 3 casas decimais (`toFixed(3)`).
## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização moderna e layout flexível.
- **JavaScript (ES6+):** Lógica de manipulação do DOM e cálculos de conversão.
